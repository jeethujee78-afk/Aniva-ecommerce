# ANIVA

### A Modern Commerce Platform for Fashion, Custom Apparel & Pre-Owned Marketplace

ANIVA is a modern fashion commerce platform designed around a premium digital shopping experience, custom apparel creation, pre-owned products, retailer participation, and a modular commerce backend.

The platform combines a cinematic fashion-focused frontend with a structured commerce engine covering product discovery, carts, inventory, checkout, orders, payments, returns, retailer workflows, authentication, and administration.

> **ANIVA — Wear the trend. Own the style.**

---

## ✨ Project Overview

ANIVA is designed as more than a traditional e-commerce storefront.

The platform brings together multiple commerce experiences:

- Fashion product discovery
- Product filtering and search
- Shopping cart
- Wishlist
- Checkout
- Order management
- Order tracking
- Customer profiles
- Custom apparel design
- Pre-owned fashion marketplace
- Retailer portal
- Product verification workflows
- Inventory management
- Payment abstraction
- Returns and refunds
- Admin operations
- AI-assisted customer styling
- Responsive premium UI

The architecture is designed to support both **direct ANIVA inventory** and **verified third-party retailer inventory**.

# 👕 Custom Print Studio

One of the core ANIVA experiences is the **Custom Print Studio**.

Customers can personalize apparel through an interactive design interface.

### Customization capabilities

- Front / back design views
- Base garment colour selection
- Size selection
- Fit selection
- Custom text
- Font selection
- Text colour
- Text sizing
- Artwork configuration
- Emblem selection
- Print placement
- Live preview
- Custom design configuration
- Add customized product directly to cart

The custom design configuration is also represented in the commerce data model so it can be associated with cart and order items.
